Conceptos Clave de Arquitectura

Glosario Técnico
view_column Segmento

Registro de 16 bits (CS, DS, SS, ES) que determina la base física o actúa como puntero selector.

Rango: 0x0000 - 0xFFFF
straighten Desplazamiento (Offset)

Distancia relativa en bytes desde el inicio del segmento hasta el byte de memoria direccionado.

IP / EIP / Punteros SP
key Selector de Segmento

Índice de 13 bits a la tabla GDT/LDT acoplado a indicador TI y nivel de privilegio solicitado (RPL).

8,192 entradas máx.
table_rows Descriptor de Segmento

Estructura de 8 bytes en memoria que define formalmente la base lineal, límite y privilegios de acceso.

GDT / LDT Segment Entry
fence Base y Límite

Inicio en memoria física/lineal y tamaño máximo accesible. Genera excepción #GP si el offset supera el límite.

Byte vs Página 4KB (Flag G)
verified_user Permisos y DPL

Protección por anillos jerárquicos de seguridad de hardware: Ring 0 (Kernel/SO) hasta Ring 3 (Usuario).

Regla: MAX(CPL, RPL) ≤ DPL
