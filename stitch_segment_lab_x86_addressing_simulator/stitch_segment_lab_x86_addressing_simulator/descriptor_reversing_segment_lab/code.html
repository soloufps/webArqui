¿Qué Significa Este Descriptor?

Este descriptor configura un segmento de CÓDIGO de 32 bits para el NÚCLEO del sistema operativo (Ring 0). Cubre todo el espacio lineal accesible de 4 GB gracias a la granularidad de 4 KB (G=1). El procesador permitirá ejecutar instrucciones desde este segmento pero bloqueará escrituras directas sobre él (ReadOnly). Solo código que se ejecute en Ring 0 podrá ser cargado en el registro CS con este selector.
