20 bits combinados de campo límite del descriptor.
Bit G (Granularidad) 1 (Páginas 4KB) Límite efectivo = 4 GB
Bit D/B (Def. Size) 1 (32-Bit Op) Punteros de 32 bits
Bit L (Long 64b) 0 (Compat. 32b) Segmento IA-32 estándar
Bit AVL (Available) 0 (Libre) Uso del SO/Kernel
Bit P (Present) 1 (En Memoria) Segmento en RAM física
DPL (Privilege) 3 (Ring 3 User) Permite acceso desde RPL 3
Bit S (System/Code) 1 (Código/Datos) No es Descriptor Sistema
Tipo (TYPE) 0010 (Datos R/W) Expand-up, No accedido
Límite Efectivo Expandido (G = 1) 4.096 GB

Fórmula: (0xFFFFF × 4096) + 4095 = 0xFFFFFFFF (4,294,967,295 bytes).
